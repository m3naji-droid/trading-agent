# 🤖 وكيل التداول الذكي — دليل التشغيل من الجوال

هذا الدليل مكتوب لشخص لا يعرف البرمجة. كل الخطوات تتم من الجوال، وتأخذ حوالي 30 دقيقة مرة واحدة فقط.
بعدها الوكيل يعمل وحده 24/7 على السيرفر، حتى لو أغلقت جوالك.

---

## ماذا يفعل الوكيل وحده؟

1. **يختار العملات:** كل 6 ساعات يختار أعلى 30 عملة سيولة على Binance (متاحة في Spot و Futures)، ويستبعد العملات المستقرة والضعيفة.
2. **يدرس تاريخ كل عملة قبل أن يتداولها:** يمر على آخر 1000 ساعة من تاريخها كأنه يتداول فيها، ويحفظ نتيجة كل فرصة في ذاكرته. لا يدخل أي عملة قبل دراستها.
3. **يحلل كل دقيقة من عدة زوايا:**
   - حالة السوق (صاعد / هابط / عرضي / خطر) على فريم الساعة.
   - مفاهيم الأموال الذكية: FVG، Order Blocks، سحب السيولة، كسر الهيكل، مناطق التجميع والتصريف.
   - تدفق الأوامر: عدم توازن دفتر الأوامر، صفقات الحيتان الكبيرة، معدل التمويل، وبث التصفيات المباشر من Binance.
4. **يختار الاستراتيجية حسب حالة السوق:** الزخم والاختراق أو الارتداد مع الاتجاه في الأسواق الاتجاهية، والارتداد للمتوسط في السوق العرضي، وانعكاس الأموال الذكية في الحالتين. إذا دخل البيتكوين حالة خطر، يوقف الدخول ويحمي المحفظة.
5. **يتعلم باستمرار:** كل إشارة (حتى التي لم ينفذها) تُتابع كصفقة تجريبية موازية. نتائجها تعيد ترتيب ثقته بكل استراتيجية في كل حالة سوق، مع تركيز أكبر على الأحدث ليتكيف بسرعة.
6. **يتذكر أخطاءه:** قبل كل صفقة يبحث في ذاكرته عن صفقات بظروف مشابهة جداً. إذا خسر هذا النمط 70% من المرات أو أكثر، يرفضه.
7. **يقرر الحجم والرافعة والسوق وحده:** مخاطرة 1% إلى 2% حسب الثقة، والرافعة حسب الثقة والتذبذب.
8. **يدير الصفقة حتى النهاية:** وقف خسارة متحرك بعد +1R، وخروج عند الهدف أو عند انقلاب حالة السوق أو بعد 3 أيام بلا تقدم.

### حدود الأمان الثابتة (لا يستطيع الوكيل تجاوزها)

| الحد | القيمة |
|---|---|
| المخاطرة لكل صفقة | 1% – 2% |
| بعد 3 خسائر متتالية | 0.5% حتى يربح |
| أقصى رافعة | 5x |
| أقصى عدد صفقات مفتوحة | 4 |
| مفتاح الطوارئ التلقائي | عند خسارة 6% في يوم واحد: يغلق كل شيء ويتوقف حتى اليوم التالي |

لم أجعل الوكيل "بلا خوف" في هذه الحدود تحديداً، وهذا مقصود. الجرأة في القرار شيء، والمخاطرة بالحساب كله شيء آخر. مع رأس مال صغير، رافعة عالية تكفي لمسح الحساب في حركة واحدة.

## الخطوة 1: استئجار سيرفر (حوالي 5$ شهرياً)

أنصح بـ **Hetzner** (رخيص وموثوق):

1. افتح موقع hetzner.com/cloud من متصفح الجوال وأنشئ حساباً.
2. اضغط **Add Server** واختر:
   - **Location:** Germany أو Finland. ⚠️ لا تختر سيرفراً في أمريكا، لأن Binance تحظر عناوين IP الأمريكية.
   - **Image:** Ubuntu 24.04
   - **Type:** أصغر خيار (CX22 أو ما يشبهه)
3. بعد الإنشاء ستصلك على البريد: **عنوان IP** و**كلمة مرور root**. احفظهما.

بديل: DigitalOcean (حوالي 6$) بنفس الطريقة، مع اختيار منطقة أوروبية أو سنغافورة.

## الخطوة 2: التثبيت التلقائي عند إنشاء السيرفر (Cloud config)

عند إنشاء السيرفر في Hetzner، الصق هذا في خانة **Cloud config** قبل الضغط على Create
(غيّر `MyPass2026` إلى كلمة مرور لوحة التحكم، بأحرف إنجليزية وأرقام فقط):

```bash
#!/bin/bash
apt-get update && apt-get install -y git curl
git clone https://github.com/m3naji-droid/trading-agent /root/trading-agent
cd /root/trading-agent
cp .env.example .env
sed -i "s|^DASHBOARD_PASSWORD=.*|DASHBOARD_PASSWORD=MyPass2026|" .env
bash install.sh
```

انتظر 10 دقائق بعد الإنشاء. السيرفر يثبت كل شيء وحده.

## التحديثات التلقائية

الوكيل يفحص GitHub كل دقيقة. عند وجود تعديل جديد يحمّله ويعيد تشغيل نفسه بين دورتين (خلال 1–3 دقائق)، مع الحفاظ على الذاكرة والصفقات والإعدادات. لا يحتاج أي دخول للسيرفر.
رقم الإصدار الحالي يظهر في تبويب 🧠 التعلم ← "إصدار النظام".

## الخطوة 5: افتح لوحة التحكم

افتح الرابط من متصفح جوالك، وأدخل كلمة المرور.
نصيحة: اضغط "إضافة إلى الشاشة الرئيسية" ليصبح مثل تطبيق.

في أول ساعة سترى الوكيل **يدرس تاريخ العملات** (تبويب 🧠 التعلم). بعدها يبدأ التداول وحده.

---

## الخطوة 6: الانتقال للمال الحقيقي (بعد أسبوعين إلى 4 أسابيع من المحاكاة)

لا تنتقل للحقيقي قبل أن ترى في لوحة التحكم نتائج محاكاة مقنعة على مدى أسابيع، وليس أياماً.

### إنشاء مفتاح API آمن على Binance

1. من تطبيق Binance: **Profile → API Management → Create API** واختر **System generated**.
2. في الصلاحيات فعّل **فقط**:
   - ✅ Enable Reading
   - ✅ Enable Spot & Margin Trading
   - ✅ Enable Futures
   - ❌ **Enable Withdrawals: اتركها معطلة دائماً.** الوكيل يفحص هذا بنفسه ويرفض العمل إذا كانت مفعلة.
3. اختر **Restrict access to trusted IPs only** وأدخل IP السيرفر. بهذا لا يمكن لأحد استخدام المفتاح من مكان آخر، حتى لو سُرق.
4. تأكد أن حساب Futures مفعّل في Binance، وحوّل إليه جزءاً من رصيدك.

### إضافة المفتاح للسيرفر

في Termius:

```bash
cd ~/trading-agent && nano .env
```

ضع المفتاح بعد `BINANCE_API_KEY=` والسر بعد `BINANCE_API_SECRET=`، ثم احفظ بالضغط على `Ctrl+X` ثم `Y` ثم `Enter`. بعدها:

```bash
bash update.sh
```

ثم من لوحة التحكم اضغط **🔁 تغيير الوضع** واكتب `live`.

(اختياري: يمكنك تجربة `testnet` أولاً بمفاتيح من حساب Binance التجريبي Demo Trading، لكن المحاكاة `paper` تكفي غالباً.)

## أزرار لوحة التحكم

الوكيل لا يحتاجك. هذه الأزرار للطوارئ فقط:

- **⏸️ إيقاف الدخول:** يتوقف عن فتح صفقات جديدة، ويستمر في إدارة المفتوحة حتى تُغلق.
- **🚨 مفتاح الطوارئ:** يغلق كل الصفقات فوراً ويجمّد التداول حتى تضغط "رفع التجميد".
- **🔓 رفع التجميد:** يستأنف بعد التجميد اليدوي. أما التجميد التلقائي (خسارة 6% في يوم) فيُرفع وحده في اليوم التالي.

## التعافي الذاتي

- إذا انقطع الإنترنت أو أخطأت Binance، يعيد الوكيل المحاولة تلقائياً بفواصل متزايدة.
- إذا علق البرنامج أكثر من 10 دقائق، يعيد تشغيل نفسه.
- إذا أُعيد تشغيل السيرفر، يعود الوكيل للعمل وحده بنفس ذاكرته وصفقاته.
- في الوضع الحقيقي، كل صفقة لها **وقف خسارة مسجّل على Binance نفسها**. لو توقف السيرفر تماماً تبقى صفقاتك محمية.

## أوامر مفيدة (في Termius)

```bash
cd ~/trading-agent
docker compose logs --tail=50 app     # رؤية ما يفعله الوكيل الآن
bash update.sh                         # إعادة التشغيل بعد تعديل .env
docker compose restart app             # إعادة تشغيل سريعة
```

إذا لم يفتح رابط https بعد 10 دقائق، شغّل `docker compose logs caddy` وأرسل لي الناتج.

## ⚠️ تنبيه صادق

- لا يوجد نظام تداول آلي يضمن الربح، مهما كان متقدماً. الأسواق تتغير، وأي استراتيجية قد تمر بفترات خسارة.
- التعلم يحتاج وقتاً وبيانات. أول أسابيع المحاكاة هي فترة تعلّم الوكيل.
- ضع فقط مالاً تتحمل خسارته.
- هذا ليس نصيحة مالية.

## هيكل الملفات

```
trading-agent/
├── app/
│   ├── main.py         ← السيرفر و API لوحة التحكم + المراقب الذاتي
│   ├── agent.py        ← عقل الوكيل: المسح، القرار، التنفيذ، الإدارة
│   ├── regime.py       ← كشف حالة السوق
│   ├── smc.py          ← FVG و Order Blocks وسحب السيولة والتجميع/التصريف
│   ├── orderflow.py    ← دفتر الأوامر والحيتان والتصفيات والتمويل
│   ├── strategies.py   ← الاستراتيجيات الأربع وبصمة الظروف
│   ├── learner.py      ← التعلم التعزيزي + دراسة التاريخ + المحاكاة
│   ├── memory.py       ← الذاكرة (SQLite) ورفض الأنماط الخاسرة
│   ├── risk.py         ← حجم الصفقة والرافعة ومفتاح الطوارئ
│   ├── broker.py       ← التنفيذ: محاكاة أو Binance حقيقي
│   ├── exchange.py     ← الربط بـ Binance عبر CCXT وفحص صلاحيات المفتاح
│   ├── indicators.py   ← المؤشرات الفنية
│   └── config.py       ← الإعدادات
├── static/index.html   ← لوحة التحكم (مصممة للجوال)
├── Dockerfile, docker-compose.yml, Caddyfile
├── boot.py (التحديث الذاتي من GitHub)
├── install.sh, update.sh
└── .env.example        ← نموذج الإعدادات
```
